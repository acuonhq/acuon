# Contributing to Acuon

Thanks for your interest! Acuon is in the rules-MVP phase; the most valuable contributions are template improvements, examples, translations, and feedback from real use.

## Scope

**Welcome:**
- Improvements to rules templates (`templates/`) — mode wording, cards, commands.
- New examples (`examples/`).
- Template and documentation translations.
- Bug reports and suggestions ([issues](https://github.com/acuonhq/acuon/issues)).

**Out of scope for this repository:**
- Skill Engine, MCP server, eval harness, and other backend (separate, non-OSS layer — Phase 2+).

## How to propose a change

1. Fork the repository and create a branch.
2. Make your changes; keep Cursor and Claude Code templates **in sync**.
3. Open a pull request using the template; describe your motivation.

## Developer Certificate of Origin (DCO)

The project accepts contributions under **DCO 1.1**: each commit must include a `Signed-off-by` line confirming you have the right to contribute this code under the project license (MIT).

Add sign-off automatically:

```bash
git commit -s -m "Your message"
```

The line looks like:

```
Signed-off-by: First Last <email@example.com>
```

PRs without sign-off cannot be merged. Full DCO text: <https://developercertificate.org/>.
